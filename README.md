# Payments Analytics & Performance Dashboard

**An End-to-End Data Analytics & Business Intelligence Project**

## About the Project

This project focuses on analyzing payment transactions to evaluate business performance, identify operational patterns, and generate actionable insights.

Using a synthetic dataset of 12,000 payment transactions, the analysis will explore transaction volumes, payment success rates, processing times, transaction fees, and payment method performance.

## Business Objectives

- Analyze payment transaction trends.
- Evaluate transaction success and failure rates.
- Identify the most frequently used payment methods.
- Compare transaction performance across countries.
- Investigate patterns associated with failed transactions.
- Develop interactive dashboards to support business decisions.

## Dataset

The project uses a synthetic dataset containing:

- 12,000 payment transactions.
- Six months of simulated activity (January–June 2025).
- Five countries.
- Four payment methods.
- Transaction amounts, fees, statuses, and processing times.

No real customer or financial information is included.

## Tools & Technologies

- Microsoft Excel — Data exploration and preparation.
- SQL — Data querying and analysis.
- Python — Exploratory Data Analysis.
- Power BI — Business Intelligence and visualization.
